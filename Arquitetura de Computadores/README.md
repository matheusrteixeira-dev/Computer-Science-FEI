# Arquitetura de Computadores (Computer Architecture)

Assembly programs for the Intel 8051 microcontroller. Every file starts with a header that states the task, and the code is commented line by line. The figures in [images](images) contain the original problem statements (waveforms and schematics).

| Activity | Files | Topics |
| --- | --- | --- |
| [Atividade 01](Atividade%2001) | `Ex01`–`Ex04` | Data transfer between registers and internal RAM; arithmetic with the accumulator; direct, immediate and indirect addressing ([statement](images/lab01_03.png)). |
| [Atividade 02](Atividade%2002) | `Ex01`–`Ex04` | Constants in program memory, `EQU`/`XCH`, integer division, 16-bit addition with carry. |
| [Atividade 03](Atividade%2003) | `Ex01`–`Ex03` | Register banks (RS0/RS1), rotating a bit on port P1, comparing two values. |
| [Atividade 04](Atividade%2004) | `Ex01`–`Ex04` | Loops and delay subroutines sized in machine cycles; comparison of code size and execution time. |
| [Atividade 05](Atividade%2005) | `Ex01`, `Ex02` | Array traversal: filtering elements to P1 and finding the maximum. |
| [Atividade 06](Atividade%2006) | `Lab01`, `Lab02` | Waveform generation by polling timer 0 in modes 2 and 1 ([statement 1](images/lab06_01.png), [statement 2](images/lab06_02.png)). |
| [Atividade 07](Atividade%2007) | `Lab01`–`Lab03` | The same signals generated by timer interrupts; T/C0 as an external event counter ([statement 1](images/lab07_01.png), [statement 2](images/lab07_02.png)). |
| [Atividade 08](Atividade%2008) | `Lab01`, `Lab02` | Pulse counters driven by external interrupts INT0/INT1. |
| [Atividade 09](Atividade%2009) | `Lab09` | 0–9 counter on a common-anode 7-segment display, advanced by INT0 ([statement](images/lab09_01.png)). |

## Running

The programs can be assembled and simulated in any 8051 IDE/simulator (for example, EdSim51 or MCU 8051 IDE). Timing calculations assume a 12 MHz crystal (1 machine cycle = 1 µs).
