## Running

Python 3.8+ with Tkinter (included in the standard Windows/macOS installers).

```bash
python "Laboratório 08/Exercício.py"
```

Scripts that read data files (`numeros_6_3.txt`, `usuarios.txt`, `Python.txt`, `p2-chat.txt`, `consumo.txt`, `palavras.txt`) find them relative to their own folder.
